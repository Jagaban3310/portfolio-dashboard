# PortfolioView — editable portfolio dashboard demo

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari. No installation or internet connection is required.
3. Sign in with:
   - Username: `demo`
   - Password: `portfolio123`

## Edit it
- Click **Edit report details** to change the investor name, title, period, total value, fees, and return.
- Click **Add investment** to add an activity row. Use × to delete a row.
- Edits are stored in this browser using localStorage.
- **Export JSON** downloads the current data. **Reset demo data** restores the sample values.
- To change the layout, colors, labels, or calculations, edit `index.html` in VS Code or another text editor.

## Important
This is a front-end learning/demo project. The sign-in is only a local demo gate; it is not secure authentication and does not connect to a bank or brokerage. Data shown is illustrative and is not a verified financial statement. Do not use this as a real account portal or enter real passwords. A production app would need a secure server, database, password hashing, authorization, validation, and audit logging.
